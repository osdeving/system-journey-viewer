# Support

## Getting Help

Use GitHub Issues for questions, bugs, and feature requests:

- Bug reports: use the `Bug Report` template
- Feature requests: use the `Feature Request` template

## Before Opening an Issue

- Check `README.md` and `docs/` first
- Search existing issues to avoid duplicates
- Include environment details and reproduction steps

## Maintainer Priorities

Issue triage focuses on:

1. correctness bugs and regressions
2. build/test and deployment blockers
3. security and stability concerns
4. UX/documentation improvements

## Commercial or Priority Support

No commercial SLA is currently offered.
